# Lokale KI – das deutschsprachige Praxis-Handbuch

Dieses Repository sammelt verständliche, schrittweise Anleitungen, um
Sprachmodelle auf dem eigenen Rechner zu nutzen. Der Einstieg und die
Hardware-Hinweise stehen im [Handbuch für lokale KI](docs/lokale-ki/README.md).

## Themen

- [Lokale KI einrichten, passende Hardware wählen und Fehler beheben](docs/lokale-ki/README.md)
- [Bestehende Dokumentation: Joy-Con-Maße](joy-con-maße/README.md)

## Pflegehinweis

Software-Versionen, Modellkataloge, GPU-Angebote und Stromtarife ändern sich.
Das Handbuch verlinkt auf Hersteller- und Projektdokumentation und nennt keine
unbestätigten Marktpreise oder festgeschriebenen „neuesten“ Versionen. Prüfe
die verlinkten Angaben und den Preis am Tag deiner Entscheidung.
